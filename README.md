# CCNA Core Networking & Cloud Infrastructure Labs

Welcome to my portfolio. This repository bridges my **Cisco Certified Network Associate (CCNA)** knowledge with modern **Cloud Networking and Infrastructure as Code (IaC)** concepts to build high-performance, automated environments.

## 🛠️ The High-Salary Transition Stack
*   **Networking Foundations:** CCNA, Subnetting, VLANs, Routing (OSPF, EIGRP), Firewalls, ACLs.
*   **Cloud Architecture:** AWS (VPC, Route53, Security Groups, IAM).
*   **Infrastructure as Code:** Terraform (Translating physical topologies into code).
*   **CI/CD Automation:** GitHub Actions (Automated testing of network configurations).

## 📂 Active Core Labs
*   **Lab 1:** Enterprise Subnetting & Multi-VLAN Architecture (Cisco Packet Tracer / GNS3).
*   **Lab 2 (Upcoming):** Mapping a Cisco 3-Tier Network Architecture into an AWS Multi-AZ VPC using Terraform.

## 🚀 DevOps & Automation Goals
Moving forward, every networking lab inside this repository will be automated. Instead of manually configuring routers via CLI, I will script deployment using Python/Ansity and deploy cloud network infrastructure dynamically.
